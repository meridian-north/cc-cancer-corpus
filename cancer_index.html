Before you open the map — read this

This is a map of the published literature, organized by how an agent is proposed to act — not by whether it works. It is a tool, not medical advice.

  • No efficacy claim, no recommendation — about anything, conventional or complementary.
  • Hypothesis-generating, not causal. A study under a mechanism discusses that mechanism. Indexed presence is not efficacy; co-location at a node is a question, never a verdict.
  • One standard for every agent. The same lens grades a chemotherapy drug and a disputed substance alike.
  • Inclusion is not a green light. Many substances are toxic or interfere with standard-of-care drug clearance; documented harms are shown plainly. Therapeutic doses are not characterized here.
  • Leads, not verdicts. Every decision belongs to a patient and their clinician.

This screen records that you have read these terms; it is not an access control. If this tool is hosted behind a sign-in, that gate is enforced by the host site, not by this page.

literature index — not medical advice — indexed presence is not efficacy — correlation is not causation. A row means a paper exists and was indexed under a mechanism — not that an agent works and not that it is safe. One standard grades every agent. A field a source cannot report shows "unavailable" — never zero. Results order by study-design class first (how the evidence was gathered), highest design at the top; count is only a tiebreaker within a class. Design rank is methodology, not efficacy — it says nothing about whether any agent works.
