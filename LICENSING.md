# Licensing — the layers

This release mixes content with different rights. Each layer is licensed on its own
terms; nothing here relicenses third-party material.

| Layer | What it is | Terms |
|---|---|---|
| **Code** | `cancer_bridge.py` and any scripts in this repo | **Apache-2.0** (see `LICENSE`) |
| **The index** | Our bibliographic metadata + mechanism tags (`cancer_index.*`, `mechanism_index.json`, `index_summary.json`) — facts we assembled | **CC0 1.0** (public-domain dedication). Facts and tags; reuse freely. |
| **Abstracts** | Abstract text in the full index, where openly available | © their respective **publishers/authors**. Included under their open-access terms / fair-use for indexing. We claim no rights; follow each `link` to the source of record. |
| **Full-text papers** | The journal articles themselves | **Not included.** Copyright remains with publishers. This release is index-and-links precisely to respect that. |
| **Duke database** | The USDA-ARS Phytochemical & Ethnobotanical tables | **Public domain** (U.S. Government work). Redistributed unmodified. See `DUKE_TABLES.md`. |

**In short:** our code is Apache-2.0, our index is CC0, the Duke data is public domain,
and we rehost no copyrighted full text — abstracts are shown under open terms with a
link to the source. If you reuse the index, a citation (see `CITATION.cff`) is
appreciated but not required.
